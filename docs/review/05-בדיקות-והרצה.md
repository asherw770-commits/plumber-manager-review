# בדיקות והרצה מקומית

## דרישות
Node.js 18 ומעלה (פותח על Node 24). Python 3 (רק לבניית עותק המסכים). **אין צורך ב-`npm install`** לבדיקות — הן מדמות את Firebase ו-web-push בעצמן. (`npm install` נדרש רק אם תרצה להריץ את פונקציות השרת על חשבון Firebase משלך.)

## 1. כל הבדיקות
```bash
npm test                    # = node tests/run-all.js — 35 בדיקות, בזו אחר זו (בלי מקביליות), כ-5 דקות
node tests/run-all.js money # רק בדיקות ששמן מכיל "money"
node tests/<שם>-check.js    # בדיקה בודדת
```
- הבדיקות **טוענות את הפונקציות האמיתיות מתוך `index.html`** (`api/_loadApp.js`), לא עותק.
- בדיקות שמשתמשות בגיבוי אמיתי של העסק מדלגות עליו אם הוא לא על המחשב, ורצות על נתוני דוגמה בדויים (`tests/sample-data.js`) ומקרים קבועים. **ההרצה אצלך תהיה על נתוני דוגמה בלבד** — זה צפוי.
- `calc-check --ci` ו-`perf-equiv-check` משווים לגרסה קודמת דרך git; בהעתק בלי `.git` הם רצים בלי ההשוואה (ומדווחים על כך).
- מגבלת זיכרון: כל בדיקה רצה ב-`--max-old-space-size=1536`.

## 3. להרים את האפליקציה בדפדפן (בלי Firebase, בלי כתיבה לשום מקום)
```bash
python3 tests/ui-harness/build.py /tmp/h        # בונה עותק עם נתוני דוגמה בדויים
cd /tmp/h && python3 -m http.server 8775
# פותחים: http://localhost:8775/index.html?role=admin    (גם role=owner / role=manager)
```
- **בכל הרצה על דפדפן שכבר הריץ גרסה אחרת — נקה `localStorage` של `localhost:8775` (או פתח חלון פרטי)**, אחרת האפליקציה תמזג את נתוני הדוגמה עם נתונים ישנים שנשמרו בדפדפן.
- `&access=dashboard,collection,transactions,reports,profit,customers,partners,products,tasks,erp` מגביל את הלשוניות של `owner`.
- נתונים אחרים: `node tests/sample-data.js my.json 600 3` ואז `build.py /tmp/h my.json`.
- הממשק בעברית, RTL. מובייל: DevTools → 375×812.

## 4. הרצת פונקציות השרת (אופציונלי)
דורש פרויקט Firebase משלך וחשבון שירות (`FIREBASE_SERVICE_ACCOUNT`). בדיקות השרת בריפו רצות בלי זה על Firestore מדומה. **אל תחבר פרויקט ייצור.**

## 5. מה אין
- אין בדיקות שמריצות את `firestore.rules` מול Firebase emulator (פער — ראה `07`).
- אין בדיקות UI אוטומטיות בדפדפן (הבדיקות הן על לוגיקה; מסכים נבדקים ידנית/DOM).
- אין CI בענן; ה-`pre-push` הוא hook מקומי בלבד.
