# יהודה קליין אינסטלציה - Business App

מערכת ניהול פיננסי לעסק אינסטלציה של יהודה קליין.

## תפקידים
- **אשר (מזכיר)** — Admin: כל הפעולות, ניהול משתמשים, ה-hub "ראשי" (מה מחכה לי, הודעות וואטסאפ, הודעות ליהודה, הגדרות, תצוגה מקדימה), כל הגבייה מול לקוחות ושותפים.
- **יחיאל (מנהל עסקי)** — Manager: קריאה בלבד בכל מסכי הכסף (סיכום כספי, עסקאות, לקוחות, שותפים) + "מה מחכה לי" משלו (מה השתנה מאז הביקור הקודם), הערות/דגלים לאשר, ייצוא לאקסל.
- **יהודה (בעלים)** — Owner: מסך בית פשוט (עבודות היום, מה נכנס היום, ✅ שילם לי), "עבודות ומשימות" עם כרטיס מלא וסדר ידני, שותפים וגבייה, הזמנות לקוחות + התראות. קריאה בלבד ב-Firestore עד שהמתג "יהודה מכניס בעצמו" (state/config.yehudaDirect) דולק — אז יש לו כתיבה מוגבלת (ראה firestore.rules).

## מבנה נתונים (Firestore)
מסמך אחד לכל דבר עיקרי תחת `state/`: `current` (tx/tasks/customerMeta/...), `inbox` (הודעות וואטסאפ, פוצל מ-current ב-1.10 בגלל מגבלת 1MB), `config`, `owner_actions` (תור הפעולות של יהודה כשהמתג הישיר כבוי), `manager_notes`, `wa_archive`. בנוסף `orders`/`orderPhotos` (מטופס הלקוחות ב-`/order`), `pushSubs`, `backups/YYYY-MM-DD`.

## לקוחות
`/order` — טופס פנייה ללקוחות: כתובת מלאה עם השלמה אוטומטית ממאגר הרחובות הרשמי (`api/address.js`), תמונות, זמן מועדף; שולח התראה ליהודה (`api/order.js` + `api/push-key.js`).

## פריסה
מפורס אוטומטית ב-Vercel בכל push ל-main branch. שער חישובים (`tests/calc-check.js`, ב-pre-push hook) בודק שאף מספר כספי לא זז לעומת הגרסה החיה לפני שהפוש עובר.

## Stack
- Vanilla JS + HTML (no framework), קובץ אחד
- Firebase Auth (Email/Password) + Firestore
- Vercel Hosting + Vercel Functions (`api/`)
